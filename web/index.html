📱 Truy Cập Từ Điện Thoại Qua Wi-Fi

Trình duyệt di động yêu cầu kết nối HTTPS để cho phép bật Camera.

  1. Đảm bảo điện thoại và máy tính kết nối cùng mạng Wi-Fi.
  2. Trên máy tính, mở terminal chạy: npm run dev -- --host.
  3. Nhìn vào địa chỉ IP mạng (ví dụ: https://192.168.1.x:5173/) và nhập vào trình duyệt điện thoại.
  4. Khi thấy thông báo "Kết nối không riêng tư":
    • Chrome/Android: Bấm Nâng cao (Advanced) → Chọn Tiếp tục truy cập (không an toàn).
    • Safari/iOS: Bấm Hiển thị chi tiết → Bấm Truy cập trang web này.
  5. Cấp quyền truy cập Camera khi được hỏi.
